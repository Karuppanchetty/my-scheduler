Here is a true story from web history that shows how wild the web used to be—and why inventing CSS was an absolute game-changer.

---

## 🎨 The Nightmare Era of HTML (And the Revolution of CSS)

Back in **1994**, the web was on the verge of total collapse because of a massive war between two competing web browsers: **Netscape Navigator** and **Microsoft Internet Explorer**.

```
              1994: THE BROWSER WARS
  ┌──────────────────┐      ┌──────────────────┐
  │ Netscape         │  VS  │ Internet Explorer│
  │ (Added <font>)   │      │ (Added <blink>)  │
  └────────┬─────────┘      └────────┬─────────┘
           │                         │
           └───────────┬─────────────┘
                       ▼
          [ CHAOTIC HTML CODE BASE ]
          Every page polluted with tags!

```

---

### The Problem: HTML Was Never Meant to Design Things

HTML was invented by Tim Berners-Lee purely to share plain scientific documents—just headings, paragraphs, and links. It had zero styling tags. No colors, no fonts, no backgrounds.

But as the web grew popular, people wanted beautiful websites. Browsers started inventing their own chaotic HTML tags to force design onto pages:

* Netscape invented the `<font>` tag so you could change text color:
`<font color="red" size="5" face="Arial">Welcome</font>`
* Internet Explorer invented crazy non-standard tags like `<marquee>` (to make text scroll endlessly) and `<blink>` (to make text flash).

### The Chaos

If you wanted to change your website's primary font or color, **you had to manually edit every single line of text across every single page of your entire website.**

If a site had 100 pages, you spent days editing hundreds of individual `<font>` tags. Web developers were losing their minds, and websites became bloated, unreadable code messes.

---

### Enter the Savior: Håkon Wium Lie & CSS (1996)

A Norwegian computer scientist named **Håkon Wium Lie** said: *"This is crazy. We need to separate content from design."*

He proposed a revolutionary idea: **Cascading Style Sheets (CSS)**.

```
       [ index.html ]                  [ style.css ]
   (Pure Content & Meaning)        (Pure Visual Design)
              │                              │
              └──────────────┬───────────────┘
                             ▼
                    [ Beautiful Web Page ]

```

His idea was brilliant in its simplicity:

1. Let **HTML** focus strictly on **structure** (headings, buttons, forms).
2. Create a brand new language—**CSS**—that sits in a separate file to handle **styles** (colors, grids, fonts).

### The Power Shift

Suddenly, instead of editing 5,000 `<font color="red">` tags across a massive website, a developer could open **one single `style.css` file** and write:

```css
body {
    color: #38bdf8;
    font-family: 'Segoe UI', sans-serif;
}

```

...and instantly update every single page across an entire corporation's website in **less than two seconds.** ⚡

---

## 💡 The Moral of the Story

When you just created your `index.html` and `style.css` files:

* You kept your HTML clean (`<div class="form-group">`), free of hardcoded colors or fonts.
* You put all your visual rules into `style.css`.
